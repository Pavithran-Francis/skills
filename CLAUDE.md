Skills are organized into bucket folders under `skills/`:

- `engineering/` — daily code work (from upstream mattpocock/skills)
- `productivity/` — daily non-code workflow tools (from upstream)
- `misc/` — kept around but rarely used (from upstream)
- `personal/` — Pavi's own skills, not synced from upstream
- `in-progress/` — drafts not yet ready to ship
- `deprecated/` — no longer used

Every skill in `engineering/`, `productivity/`, or `misc/` must have a reference in the top-level `README.md`. Skills in `in-progress/` and `deprecated/` must not appear in the README.

`.claude-plugin/plugin.json` is auto-generated by `scripts/generate-plugin-json.sh` — never edit it by hand. The script discovers all skills from `skills/` and `vendors/`, excluding `in-progress/`, `deprecated/`, and `plugins/` subdirectories. Run it after cloning or after merging any remote.

Each skill entry in the top-level `README.md` must link the skill name to its `SKILL.md`.

Each bucket folder has a `README.md` that lists every skill in the bucket with a one-line description, with the skill name linked to its `SKILL.md`. Bucket `README.md`s and the top-level `README.md` group entries into **User-invoked** and **Model-invoked**.

Every `SKILL.md` is either user-invoked (`disable-model-invocation: true`, reachable only by the human) or model-invoked (model- or user-reachable). For the full definitions, description conventions, and why a user-invoked skill can invoke model-invoked skills but never another user-invoked one, see [docs/invocation.md](./docs/invocation.md).

## Remotes

Four remotes feed this repo:

| Remote        | Repo                           | Provides                           |
|---------------|--------------------------------|------------------------------------|
| `upstream`    | `mattpocock/skills`            | engineering, productivity, misc    |
| `caveman`     | `JuliusBrussee/caveman`        | caveman-* skills (subtree)         |
| `superpowers` | `obra/superpowers`             | superpowers workflow skills (subtree) |
| `origin`      | `Pavithran-Francis/skills`     | personal skills, glue              |

### Syncing upstream (mattpocock/skills)

```bash
git fetch upstream
git merge upstream/main
./scripts/generate-plugin-json.sh
```

### Syncing caveman

Caveman lives as a git subtree under `vendors/caveman/`.

```bash
git subtree pull --prefix vendors/caveman caveman main --squash
./scripts/generate-plugin-json.sh
```

### Syncing superpowers

Superpowers lives as a git subtree under `vendors/superpowers/`.

```bash
git subtree pull --prefix vendors/superpowers superpowers main --squash
./scripts/generate-plugin-json.sh
```

Keep personal skills in `skills/personal/` to minimize merge conflicts with upstream updates. Since `plugin.json` is auto-generated, conflicts on it after any merge can be resolved by accepting either side and re-running the script.
